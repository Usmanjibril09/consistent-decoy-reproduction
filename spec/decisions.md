D28 2026-11-03 Training specification (approved). (1) Budget option (a): 12 configurations x seed 0 for selection; best configuration retrained with seeds 1-4; results over seeds 0-4; identical budget and early stopping (200 epochs max, patience 10, val loss) for every learned method. Ablations reuse the selected C1 configuration (A3 retrained, seeds 0-4; A1/A2/A4/A5 reuse C1 weights). (2) Free-run: responses predicted from warm-up state and commands only; real responses only in warm-up (HAI 60 s, QAPPD 100 samples); real attacks warm up on the 60 s before onset. (3) Windows: HAI 60+300 s, QAPPD 100+500 samples, stride 180/300; windows touching masked rows or D27 file edges dropped; z-score from training split; constant tags not modelled. (4) Selection: command-conditioned methods by validation free-run FIT% (mean over response tags); unconditioned generators and RCGAN by K-dev discriminative score; unconditioned baselines evaluated as published. (5) Fixed 12-configuration grids in configs/experiment.toml [train.grid]. (6) C2 uses physical actuator range where known, training range otherwise (training-range clipping would fail A103 by construction). (7) C3: w = min(1, excess/(0.05 x training range)), output (1-w) C1 + w B3. (8) K-dev 1D-CNN on validation windows; K-test and P-real untouched until Phase 3. (9) Every run logs commit, config hash, data hashes, package versions, device; GPU nondeterminism stated. Execution: local smoke test must pass for every method before any Kaggle run; resumable checkpoints per run.
